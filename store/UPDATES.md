# سياسة تحديث التطبيق بعد النشر

هذه النقطة مثبتة للمشروع لأننا نريد نشر التطبيق والاستمرار في تطويره.

## القاعدة الأساسية
`applicationId` = `com.tempinbox.privateinbox` يبقى ثابتًا.

مفتاح Release المستخدم في الإصدار الأول يبقى ثابتًا كذلك. تغيير أحدهما بعد النشر سيمنع تحديث التطبيق المثبت باعتباره الإصدار نفسه.

## أرقام الإصدارات
الإصدار الحالي:
- versionName = `1.0.0`
- versionCode = `1`

أمثلة لاحقة:
- 1.0.1 -> code 2
- 1.1.0 -> code 3
- 2.0.0 -> code 4

المهم أن versionCode يزداد في كل إصدار جديد.

## عند كل تحديث
عدّل فقط ما يلزم: الكود، `APP_VERSION_NAME`, `APP_VERSION_CODE`, changelog، لقطات الشاشة، وسياسة الخصوصية إذا تغير التعامل مع البيانات.

ثم ابنِ Release APK موقّع بالمفتاح نفسه.
