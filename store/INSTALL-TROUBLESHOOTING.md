# تثبيت التطبيق وحل رسالة «الحزمة ليست مثبّتة»

## لماذا قد تظهر الرسالة؟

أكثر سبب شائع عند التثبيت على جهاز واحد فقط هو وجود نسخة سابقة من التطبيق موقعة بمفتاح مختلف عن نسخة Release المنشورة. كذلك قد يكون الجهاز أقدم من `minSdk` أو قد يكون الملف المنشور ليس APK واحدًا مناسبًا للتثبيت المباشر.

## ما تم تثبيته في هذا المشروع

- Release يبقى على `applicationId` الثابت: `com.tempinbox.privateinbox`.
- Debug أصبح بحزمة منفصلة: `com.tempinbox.privateinbox.debug`، لذلك لا يتعارض مع Release من ناحية التوقيع.
- Release يستخدم V1 + V2 + V3 APK signing schemes عند توفر مفتاح الإصدار.
- لا توجد ABI splits في المشروع؛ نسخة APK العادية هي ملف واحد.
- مفتاح Release الخاص يجب أن يبقى نفسه في كل تحديث.

## عند اختبار APK المنشور

إذا كانت هناك نسخة قديمة من التطبيق موقعة بمفتاح مختلف، احذف النسخة القديمة ثم ثبّت النسخة المنشورة الجديدة. لا تحذف نسخة منشورة سليمة لمجرد الاختبار قبل التأكد من أنك تملك مفتاح الإصدار نفسه.
