# Final submission checklist

## Identity and release
- App name: بريد مؤقت
- applicationId: `com.tempinbox.privateinbox`
- Version: 1.0.0 / code 1
- Release signing: PKCS12, alias `temp-email-release`
- Certificate SHA-256 matches `store/signing-certificate.md`
- No ads / no IAP / no subscription in 1.0.0

## APKPure
- Developer account created
- Upload the signed release APK
- Keep applicationId stable for all future updates
- Use the same release signing key for all future updates
- Use the square 512x512 icon
- Use 5+ real screenshots from the installed APK
- Accurate short/full description
- Privacy policy URL hosted publicly
- What's New/changelog for 1.0.0

## Uptodown
- Developer Console account
- Submit one signed APK
- Square PNG icon, at least 256x256
- Official website URL
- Author/developer name
- Featured image exactly 1024x500
- At least 4 real Android screenshots
- Short description <= 70 characters
- Full description
- Version 1.0.0
- Development stage: Final Release
- Distribution Model: Free
- IAP: No
- Subscription: No
- Ads: No
- Languages: Arabic, English
- Changelog

## Must be completed by the account owner
- Replace the developer contact placeholder in the privacy policy.
- Publish `docs/` and use the real public URL in store forms.
- Keep the release keystore in at least two secure private backups.
- Take real screenshots from the final APK; do not use mockups as store screenshots.
- Build and install-test the signed release before submission.
